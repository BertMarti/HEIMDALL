La idea sencilla

¿Qué es HEIMDALL?

Una VPN es como un túnel privado entre tu dispositivo y tu casa. HEIMDALL lo construye con WireGuard y lo administra desde un panel web.

Entra en casa desde fuera

Accede a tus aplicaciones y a tu red doméstica cuando estás fuera, como si siguieras conectado a tu Wi-Fi.

Más tranquilidad en Wi-Fi pública

Usa tu conexión de casa al navegar desde una red pública, con el túnel WireGuard activo.

Bloqueo de anuncios fuera

Si tienes SHIELD-DNS instalado, tus dispositivos conectados también pueden llevarse ese bloqueo a todas partes.

Panel y QR, sin líos

Crea dispositivos desde el panel, escanea un QR en el móvil o descarga un archivo .conf. Es gratis, autoalojado y con licencia MIT.

Sin magia negra

Instalar, paso a paso

Sigue el orden. Los valores son ejemplos: 192.168.1.50 es la máquina de HEIMDALL y 192.168.1.1 el router.

01

Comprueba los requisitos

Raspberry Pi 4/5 de 64 bits o PC/mini-PC con Debian, Ubuntu u otra distribución Linux. Necesitas una IP fija en casa, acceso al router y una IP pública sin CG-NAT. Docker Compose v2 se instala si falta.

02

Prepara la máquina

sudo apt update && sudo apt install -y git openssl curl

¿Quieres SHIELD-DNS? Instálalo antes para que HEIMDALL lo use como DNS automáticamente.

03

Clona e instala

mkdir -p ~/homelab && cd ~/homelab
git clone https://github.com/BertMarti/HEIMDALL.git
cd HEIMDALL
./install.sh
04

Abre el panel en casa

Visita https://192.168.1.50:51843. Acepta el aviso del certificado propio. La contraseña está en:

grep WG_ADMIN_PASSWORD ~/homelab/HEIMDALL/.env
05

Abre solo el puerto necesario

En el router crea un reenvío UDP 51820 → 192.168.1.50:51820. No abras nunca el panel TCP 51843 a Internet.

¿Quieres todo el ecosistema? El instalador de ARIA prepara las aplicaciones en el orden correcto.
curl -fsSL https://raw.githubusercontent.com/BertMarti/ARIA/main/instalar-todo.sh | bash

El día a día

Usar HEIMDALL

Una vez instalado, añadir un dispositivo es cuestión de un minuto.

Móvil o tablet con QR

  1. Instala WireGuard desde App Store o Google Play.
  2. En HEIMDALL, crea un cliente nuevo y pulsa el icono QR.
  3. En WireGuard, toca + y escanea el código.
  4. Activa el túnel.

Si pierdes un móvil, desactívalo o bórralo en el panel cuanto antes.

Ordenador

Instala WireGuard, descarga su archivo .conf desde el panel e impórtalo como túnel.

Android TV

Las teles con Android TV o Google TV pueden instalar WireGuard e importar el QR o el archivo .conf.

IP que cambia

Usa DuckDNS gratis con un nombre como micasa.duckdns.org para que tu dirección siga apuntando a casa.

Cuando algo no encaja

Preguntas frecuentes

Desde fuera de casa no conecta

Comprueba el reenvío UDP 51820 hacia 192.168.1.50 y prueba con el móvil usando datos, no Wi-Fi. Mira si aparece un último handshake.

¿Tengo CG-NAT?

Compara la IP WAN del router con la que muestra un servicio de consulta de IP pública. Si no coinciden, o empieza por 100.64. hasta 100.127., pide una IP pública a tu operador. DuckDNS no lo soluciona.

Conecta pero no navega

Revisa el DNS de la VPN. Si usas SHIELD-DNS, comprueba que está en marcha con docker ps.

Dejó de funcionar tras unos días

Probablemente cambió tu IP pública. Configura DNS dinámico con DuckDNS.

Olvidé la contraseña del panel

Si nunca la cambiaste desde el panel, consulta grep WG_ADMIN_PASSWORD .env. Si la cambiaste, el valor de .env no se actualiza solo.

¿Funciona en Windows?

No. HEIMDALL necesita una máquina Linux; WireGuard dentro de WSL2 o Docker Desktop no recibe conexiones de fuera de forma fiable.

¿Es gratis?

Sí. HEIMDALL es autoalojado y tiene licencia MIT. Tú pones la máquina y la conexión de casa.

¿Cómo hago copias de seguridad?

Ejecuta ./backup.sh. Guarda la copia fuera de la máquina y en un sitio seguro: contiene las claves privadas del servidor y de los dispositivos.
